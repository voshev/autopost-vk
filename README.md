# autopost-vk
Автопостинг случайных товаров из VK-маркета группы вконтакте средствами VK API

`autopost.sh` – добавьте ключ доступа пользователя-администратора группы и её идентификатор. 


`bash autopost.sh` – запущенный скрипт выберет случайный товар из маркета группы, соберёт фотографии, название, цену и опубликует запись на стене группы.

Подробнее: [статья на моём сайте](https://artbobylev.ru/posts/vk-post-automatization-howto/)
